## Metsu mode

This fork adds Irisu Syndrome's Metsu (nonzero) mode as a second gameplay mode,
reverse-engineered from `irisu.exe` (see `docs/metsu.md` for the recovered
rules). The web app has a **NORMAL ⇄ METSU** button in the header that starts a
fresh run in the other mode; replays are saved and loaded with mode byte 1 and
`metsu_*.rpy` filenames. Normal mode still runs on the exact v2.03 worker.
